# Evidências de hardware

Coloque aqui apenas fotografias e transcrições **revisadas** para publicação. Guarde os arquivos originais em local privado. Para cada evidência, registre: ID, data, dispositivo/revisão, método de coleta, hash SHA-256 do original, alterações de redação e qual afirmação ela sustenta. Não publique números de série completos, credenciais ou dados pessoais.
